# Sponsor logos

The sponsor list is maintained in `data/sponsors.ts`. Images are served locally
from `public/logos/sponsors/`; no logo API, API key, or external image host is
needed at runtime. Logos retain their original colors. Reversed logos use dark
backgrounds so their white lettering remains visible.

Assets were retrieved from the following company websites or company-issued
press materials. The Disney and DraftKings files are their published inline SVG
wordmarks. Disney's HTML-lowercased SVG attributes were restored to XML casing
(`viewBox` and `clipPath`) for use as a standalone image.
